# Tillbahrain

Tillbahrain is a Bahrain-native, offline-first retail POS and store operating system for Windows.

## Product identity

- Product: **Tillbahrain**
- Package: `tillbahrain`
- Desktop identifier: `com.tillbahrain.pos`
- Initial target version: `1.0.0`
- Primary OS: Windows 10/11 x64
- Currency default: BHD (3 decimal places)
- Timezone default: `Asia/Bahrain`
- Languages: English and Arabic/RTL
- Mode: retail only

## Engineering status

Greenfield implementation started 2026-10-03 from the approved Tillbahrain Master Development Directive. Work is gated by tests, CI, security checks, and Windows clean-install acceptance. The project must not be described as complete until those gates have evidence.
